# LonyxWeb V1 — entrega completa

[Baixar o ZIP completo](https://github.com/rdgzinop223-png/Sites01/raw/refs/heads/main/LonyxWeb-V1.zip)

O arquivo inclui o código-fonte, a versão compilada, o vídeo original, assets e capturas reais.

## Executar a versão pronta

Extraia o ZIP, entre na pasta `lonyxweb` e execute:

```bash
npm start
```

Abra http://localhost:3000. É necessário ter Node.js e npm instalados.

## Desenvolver

```bash
cd lonyxweb
npm ci
npm run dev
```

[Documentação completa](lonyxweb/README.md) · [Validação e testes](lonyxweb/VALIDACAO.md)
